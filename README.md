✨ Interactive To-Do List with LocalStorage

A simple and responsive task management web application built using HTML, CSS, and JavaScript.

🚀 Features

- Add new tasks
- Add tasks using the Enter key
- Mark tasks as completed
- Delete tasks
- Save tasks using browser LocalStorage
- Retain tasks after refreshing the page
- Responsive design for mobile and desktop
- Safe rendering of user-entered task text

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Listeners
- Browser LocalStorage

📂 Project Structure

interactive-todo-list/
├── index.html
├── style.css
├── script.js
└── README.md

💻 How to Run

1. Clone or download this repository.
2. Open "index.html" in a web browser.
3. Add tasks using the input field.
4. Mark tasks as completed or delete them.
5. Refresh the page to verify that tasks remain saved.

💾 Data Persistence

Tasks are stored in browser LocalStorage using "JSON.stringify()" and retrieved using "JSON.parse()".

The data remains available in the same browser and website origin unless browser storage is cleared.

🎨 Design Decision

I chose a clean purple-and-white interface to create a simple, modern, and user-friendly experience. The responsive layout makes the application convenient to use on both mobile devices and desktop screens.
